# 🧠 สมองมึงคิดเหมือนกูไหม? — 15 รอบ / 200 คำถาม

เว็บเกม 2 คนแบบ Real-time สำหรับเล่นกับเพื่อน

## เวอร์ชันนี้
- เล่นทั้งหมด **15 รอบ**
- มีคำถามทั้งหมด **200 คำถาม**
- ในแต่ละเกมระบบจะ **สุ่มคำถาม 15 ข้อจากคลัง 200 ข้อ**
- ภายในเกมเดียวกันจะไม่สุ่มคำถามซ้ำ
- เริ่มเกมใหม่จะสุ่มชุดใหม่อีกครั้ง
- คะแนน:
  - ตรงกัน = +100 ต่อคน
  - ไม่ตรงกัน = +10 ต่อคน

## วิธีรัน

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm start
```

เปิด:

```text
http://localhost:3000
```

## เล่นกับเพื่อนในเครื่องเดียวกัน
เปิด 2 แท็บ → คนแรกสร้างห้อง → คนที่สองใส่ Room Code

## เล่นผ่าน Wi-Fi เดียวกัน
ให้เพื่อนเปิด:

```text
http://IP-เครื่องที่รันเซิร์ฟเวอร์:3000
```

ตัวอย่าง:

```text
http://192.168.1.20:3000
```

## โครงสร้าง
- `server.js` — Express + WebSocket + ห้องเกม + คำถาม 200 ข้อ
- `public/index.html` — UI
- `public/style.css` — UI/Responsive
- `public/app.js` — client game logic

หมายเหตุ: เวอร์ชันนี้ยังไม่มีฐานข้อมูล/Login จึงเหมาะกับ MVP และการทดลองเล่นกับเพื่อน
